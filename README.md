## `## how I think in systems`

```
  Clients ▶ Edge/CDN ▶ Node/Express ▶ ┌ Auth svc ┐ ▶ Jobs/Queue ▶ ┌ Postgres ┐
                                      │ Catalog  │                │ MongoDB  │
                                      └ Payments ┘                └ MySQL    ┘
```

- **find the seams** — boundaries follow how the business actually changes, not the org chart.
- **make state explicit** — events over hidden mutations. If you can replay it, you can reason about it at 3am.
- **optimize for the next person** — the best architecture is the one a new hire understands by Friday.
